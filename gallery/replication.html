Original against replication

One hundred findings, each measured twice. The chart is an ordinary scatterplot, and the whole argument lives in one line that carries no data: the diagonal where the two measurements would agree.

THE ORIGINAL

“RPP_Figure3” from the Reproducibility Project: Psychology materials by the Open Science Collaboration, via osf.io/ezcuj, dedicated to the public domain under CC0 1.0. The collaboration’s own figure, not the Science typeset version, which is AAAS copyright.

The Reproducibility Project: Psychology repeated 100 published studies with high power and preregistered protocols, then plotted each original effect size against its replication. Point size is the replication’s power, and colour is whether it reached significance.

How to read it

Each point is one study, measured twice. Horizontal position is the effect the original paper found; vertical position is what the replication found.

The diagonal is where a point would land if the replication matched the original exactly. It encodes nothing; it is a standard of comparison drawn on the page.

Below the line means the replication found a weaker effect. Distance from the line, not position on the page, is the quantity you are meant to read.

Colour marks whether the replication reached significance, which is a second and much cruder summary of the same thing.

THE CRITIQUE

01 · Describe

A square scatterplot with identical scales on both axes, a diagonal reference line, and roughly a hundred points. The points sit overwhelmingly on one side of the line. Density curves run along the margins.

02 · Analyse

Two measurements of the same quantity on two positional axes, which is the right call. The decision that makes it work is forcing the axes to share a scale and drawing the identity line. Without those, this is an unremarkable positive correlation; with them, every point’s vertical distance from the line is a readable quantity.

03 · Interpret

The claim is that published effects in psychology are, on average, substantially larger than what a careful repeat finds. The asymmetry about the line is the finding, and it is visible before any number is read.

04 · Judge

Well made, and honest about being a distribution rather than a verdict: points above the line exist, and the figure does not hide them. What it cannot show, and does not claim to, is why each point fell where it did: publication bias, low original power and genuine differences between the studies all produce the same picture.

THE RECREATION

# The original's two colours are ggplot2's own defaults for a two-level factor
# — see the note below. Matching them is part of recreating the figure.
osc_pal <- c("Not Significant" = "#F8766D", "Significant" = "#00BFC4")

main <- ggplot(rpp, aes(orig, rep)) +
  geom_abline(slope = 1, intercept = 0, colour = "#8a8a82", linewidth = .4) +
  geom_hline(yintercept = 0, colour = "#3a3a34", linewidth = .35, linetype = "22") +
  # rug marks on both axes, as the original has
  geom_rug(aes(colour = sig_orig), sides = "b", linewidth = .3, alpha = .75,
           length = unit(.018, "npc"), show.legend = FALSE) +
  geom_rug(aes(colour = sig), sides = "l", linewidth = .3, alpha = .75,
           length = unit(.018, "npc"), show.legend = FALSE) +
  geom_point(aes(colour = sig, fill = sig, size = power), shape = 21,
             stroke = .35, alpha = .75) +
  scale_colour_manual(values = osc_pal, name = "p-value") +
  scale_fill_manual(values = osc_pal, guide = "none") +
  scale_size_continuous(name = "Replication Power", range = c(1, 5.5),
                        breaks = c(.6, .7, .8, .9)) +
  coord_cartesian(xlim = c(-.06, 1), ylim = c(-.55, 1.05)) +
  labs(x = "Original Effect Size", y = "Replication Effect Size") +
  theme_dsvar(base_size = 10) +
  theme(legend.position = "inside",
        legend.position.inside = c(.86, .62),
        legend.background = element_rect(fill = "#faf8f4", colour = NA),
        legend.key.size = unit(10, "pt"),
        legend.title = element_text(size = 7.5),
        legend.text = element_text(size = 7),
        legend.spacing.y = unit(1, "pt"))

# Marginal densities, filled and semi-transparent so the overlap shows, exactly
# as in the original.
# after_stat(count) scales each curve by its group size. Without it geom_density
# normalises every group to area 1, so the 7 non-significant originals would get
# as much ink as the 90 significant ones — which is not what the original shows,
# and is a good illustration of how a default can quietly restate the data.
top <- ggplot(rpp, aes(orig, after_stat(count), fill = sig_orig, colour = sig_orig)) +
  geom_density(alpha = .55, linewidth = .3) +
  scale_fill_manual(values = osc_pal, guide = "none") +
  scale_colour_manual(values = osc_pal, guide = "none") +
  coord_cartesian(xlim = c(-.06, 1), expand = FALSE) +
  theme_void()

right <- ggplot(rpp, aes(rep, after_stat(count), fill = sig, colour = sig)) +
  geom_density(alpha = .55, linewidth = .3) +
  scale_fill_manual(values = osc_pal, guide = "none") +
  scale_colour_manual(values = osc_pal, guide = "none") +
  coord_flip(xlim = c(-.55, 1.05), expand = FALSE) +
  theme_void()

# patchwork's guides="collect" is broken against ggplot2 4.x, so the legend
# lives inside the main panel and the margins are laid out by design widths.
library(patchwork)
top + plot_spacer() + main + right +
  plot_layout(ncol = 2, widths = c(4, 1), heights = c(1, 4))

34 of 97 replications reached p < .05, against 90 of 97 originals. Mean effect size fell from r = 0.4 to r = 0.2, roughly halved. Each margin is coloured by its own axis’s significance, which is why the top is almost entirely teal: the originals were published findings, so nearly all of them were significant.

WHAT THE DIAGONAL IS WORTH

The line carries no data. Take it away and see what happens to the argument.

Show the R code 
twice <- bind_rows(mutate(rpp, v = "Without the reference line"),
                   mutate(rpp, v = "With it")) |>
  mutate(v = factor(v, levels = c("Without the reference line", "With it")))

ggplot(twice, aes(orig, rep)) +
  geom_abline(data = filter(twice, v == "With it"),
              aes(slope = 1, intercept = 0), colour = "#5a5a52",
              linewidth = .5, linetype = "22") +
  geom_point(colour = dsvar_accent(), size = 1.5, alpha = .75) +
  facet_wrap(~v) +
  coord_equal(xlim = c(-.5, 1), ylim = c(-.5, 1)) +
  labs(x = "Original effect size (r)", y = "Replication effect size (r)",
       title = "Identical points. One line added.",
       caption = "n = 97 study pairs")

On the left this is a positive correlation with a lot of scatter, and a reasonable reader concludes that replications broadly recover the originals. On the right the same points are obviously lopsided. A reference line is an argument about what counts as agreement. Drawing one, or leaving it out, costs nothing and changes what the reader concludes.

WHAT THE SCATTERPLOT WILL NOT TELL YOU

  geom_line(colour = "#a5a199", linewidth = .3, alpha = .7) +
  geom_point(colour = dsvar_accent(), size = .9, alpha = .7) +
  facet_wrap(~field) +
  labs(x = NULL, y = "Effect size (r)",
       title = "The same 97 studies, as paired measurements",
       subtitle = "Almost every line slopes down, and further in social than in cognitive psychology",
       caption = "n = 97 study pairs · field as classified by the original authors")

WHAT THIS PAGE IS NOT CLAIMING

That 63 of 97 findings were false. A replication that misses significance is evidence, not a verdict: it can also reflect a smaller true effect, a different sample, or an honest difference in procedure. The figure shows a distribution of outcomes, and the course’s interest is in how it shows it. The inference is a much longer argument, and the original paper makes it carefully.
