Cartograms and hexbin maps

A map is a chart whose areas were decided by geology. Colour those areas by something about people and the biggest, emptiest places shout loudest. Land does not vote, commit crimes or catch diseases, and the choropleth is the chart form that keeps forgetting it.

THE ORIGINAL

“2020 United States presidential election results map by county” by Magog the Ogre, via Wikimedia Commons, dedicated to the public domain under CC0 1.0.

“Results by county of the 2020 United States presidential election with counties scaled by number of votes cast” by Drlovedrake, via Wikimedia Commons, licensed CC BY-SA 4.0. It keeps that licence here rather than the site’s.

The first is the map everyone sees on election night. Biden won this election by seven million votes, and you would not guess it from the ink. The second keeps every county and every county’s colour, and corrects only the areas: the result is a different country.

The problem is oldest and clearest in election maps, where an empty county can take hundreds of thousands of times as much ink per vote as a dense one. That ratio is measured further down this page.

How to read it

A choropleth fills each region with a colour. The quantity is on colour; the area is geography and carries no information at all.

But area is what the eye adds up. A reader sums coloured ink, so the map reports land area weighted by your variable, which is nobody’s question.

A cartogram rescales the regions so that area encodes the thing that matters, usually population. Geography is sacrificed on purpose.

A hex or tile map goes further: every region becomes an identical cell, so area carries nothing and only position hints at geography.

THE CRITIQUE

01 · Describe

Two maps of the same result. In the first, regions are filled with a colour and their outlines follow real borders, so a few enormous counties dominate the frame. In the second the outlines have been deformed until each county’s area matches its votes, and the familiar shape of the country is gone.

02 · Analyse

Two channels are in play and only one was chosen. Colour carries the variable and is a weak channel. Area carries nothing intentionally and is a strong one. The chart therefore has a loud, uncontrolled encoding sitting on top of a quiet, deliberate one.

03 · Interpret

Whatever the author meant, what a reader takes away is roughly “how much of the map is this colour”, which is a statement about territory. For anything measured on people, that is the wrong denominator before the colour scale is even chosen.

04 · Judge

Defensible only when the quantity really is about land, or when it has already been normalised and the reader is being asked where, not how much. Two fixes exist and they are different: normalising turns counts into rates and keeps the geography; a cartogram keeps the counts and throws the geography away. Choosing between them is choosing which question the map answers.

THE RECREATION

Both originals, from the same 3,152 county results and the same county outlines. Nothing changes between the two panels except what area means.

# The Dorling: every county becomes a circle at its centre, area = votes cast.
# A true contiguous cartogram deforms the borders instead; the circle version
# makes the same correction and is reachable with a geom you already know.
dorling <- ggplot(centroids, aes(long, lat)) +
  geom_polygon(data = states, aes(long, lat, group = group),
               fill = "#f2f0ea", colour = "white", linewidth = .2) +
  geom_point(aes(size = total_votes, fill = margin), shape = 21,
             colour = "white", stroke = .15) +
  coord_quickmap() +
  scale_size_area(max_size = 11, guide = "none") +
  scale_fill_gradientn(colours = vote_cols, limits = c(-1, 1),
                       na.value = "grey80", guide = "none") +
  labs(title = "Area corrected to votes: a Dorling cartogram",
       subtitle = "Same counties, same colours. Only the areas were fixed") +
  theme_void(base_family = dsvar_font()) +
  theme(plot.title    = element_text(face = "bold", size = 11, hjust = 0),
        plot.subtitle = element_text(size = 9, colour = "#5a5a52", hjust = 0))

choropleth / dorling

3,152 counties in the results file; 99.4% of the map’s polygon vertices join to one. The misses are the known awkward cases (independent cities, Alaska’s boroughs, counties renamed since the maps outlines were drawn), and they render grey. Alaska and Hawaii are absent from the outlines entirely.

A DORLING IS NOT THE SAME AS THE ORIGINAL CARTOGRAM

Drlovedrake’s map is contiguous: the county borders themselves are pushed and stretched until each area matches its votes, so the country stays joined up and stays recognisable. The Dorling here replaces each county with a circle instead. It makes the identical correction (area now means votes) and needs nothing beyond geom_point(), but it gives up the borders. Contiguous cartograms need an iterative algorithm over real polygons (the cartogram package, on sf geometry). The point being taught survives the substitution, which is why it is here.

THE MISMATCH, STATED DIRECTLY

# The two extremes of the map-ink-per-vote ratio, plus the two biggest counties
# by each of the axes.
big <- county_area |>
  slice_max(area, n = 2) |>
  bind_rows(slice_max(county_area, total_votes, n = 2),
            slice_max(county_area, area / total_votes, n = 1),
            slice_min(county_area, area / total_votes, n = 1)) |>
  mutate(label = paste0(str_remove(county_name, " County"), ", ",
                        state.abb[match(state_name, state.name)]))

ggplot(county_area, aes(area, total_votes)) +
  geom_point(colour = dsvar_accent(), size = .7, alpha = .25) +
  ggrepel::geom_text_repel(data = big, aes(label = label), size = 2.8,
                           family = dsvar_font(), seed = 4, box.padding = .6,
                           segment.size = .2, bg.color = "#faf8f4", bg.r = .12) +
  scale_x_log10(labels = scales::label_comma()) +
  scale_y_log10(labels = scales::label_comma()) +
  labs(title = sprintf("Land area tells you nothing about votes (r = %.2f)",
                       cor(log(county_area$area), log(county_area$total_votes))),
       subtitle = "US counties, 2020 presidential election. Both axes logarithmic",
       x = "Land area (square miles, log)", y = "Votes cast (log)",
       caption = sprintf("n = %s counties · area computed from the polygon outlines",
                         scales::comma(nrow(county_area))))

The correlation is -0.05: on logarithmic axes, across three thousand counties, land area and voters are unrelated. Loving County, Texas gets 9 square miles of map per vote. Manhattan gets one square mile for every 38,899 votes.

Every square mile gets an equal vote in the reader’s impression, and square miles are handed out almost independently of people.

COUNTS AND SHARES ARE DIFFERENT MAPS

county_map(votes_dem, "Democratic votes, as a count",
           "Los Angeles sets the scale and flattens everything else", "Votes",
           scales::label_number(scale_cut = scales::cut_short_scale())) +
county_map(per_dem, "Democratic votes, as a share",
           "Normalised: a completely different map", "Share",
           scales::label_percent())

Same data, same outlines, same colour ramp. The left map is unreadable because one county (Los Angeles, with 3,028,885 Democratic votes) sets a scale nothing else can compete on. The right map is readable and answers a different question.

NORMALISING AND RESCALING ARE NOT THE SAME FIX

The share map and the cartogram both repair the count map, and they answer different questions. Normalising keeps real geography and tells you where support was strong, but it makes a county of 400 voters as visually important as one of two million, so a handful of ballots in an empty county shouts. A cartogram keeps the magnitudes and destroys the geography, so regional pattern becomes hard to read. The Dorling above does both at once (area for voters, colour for margin), which is usually the honest compromise and is also the least familiar to readers.

THE OPTION NOBODY OFFERS YOU

Show the R code 
by_state <- elec |>
  summarise(dem = sum(votes_dem), gop = sum(votes_gop),
            votes = sum(total_votes), .by = state_name) |>
  mutate(margin = (dem - gop) / votes)

ggplot(by_state, aes(margin, fct_reorder(state_name, margin))) +
  geom_vline(xintercept = 0, colour = "#a5a199", linewidth = .4) +
  geom_segment(aes(xend = 0, yend = fct_reorder(state_name, margin)),
               colour = "#d8d3c7", linewidth = .3) +
  geom_point(aes(size = votes, fill = margin), shape = 21,
             colour = "#8a867e", stroke = .25) +
  scale_size_area(max_size = 5.5, guide = "none") +
  # Squished at +/- 40 points: state margins never approach the +/- 100 the
  # county map needs, so the county scale would leave every state near-white.
  scale_fill_gradientn(colours = vote_cols, limits = c(-.4, .4),
                       oob = scales::squish, guide = "none") +
  scale_x_continuous(labels = scales::label_percent()) +
  labs(title = "The same election, ranked instead of mapped",
       subtitle = "Dot size is votes cast. Precise, sortable, and not a map",
       x = "Margin (Democratic − Republican)", y = NULL,
       caption = sprintf("n = %d states and DC · county results summed",
                         nrow(by_state) - 1L)) +
  theme(axis.text.y = element_text(size = 6.5))

Before reaching for any map, ask whether the reader’s question is geographic. “Which states were closest?” is a ranking question and a sorted dot plot answers it better than every map on this page. A map earns its place when the answer is spatial: when neighbouring regions resembling each other is part of the finding. If you cannot say what the geography is contributing, you have drawn a very expensive bar chart.
