The asymmetric media ecosystem

Network maps of who links to whom have become the standard picture of political polarisation. They are also the chart form where the layout algorithm does more of the arguing than the data does, and the reader has no way to tell.

THE ORIGINAL

Figure 2.1, “Network map of election media sources based on media inlinks”, from Benkler, Y., Faris, R., & Roberts, H. (2018). Network Propaganda: Manipulation, Disinformation, and Radicalization in American Politics. Oxford University Press. © Yochai Benkler, Robert Faris and Hal Roberts 2018, published open access under CC BY-NC-ND 4.0. Reproduced unmodified, with its caption, from the OAPEN edition. Maps generated with Media Cloud.

Yochai Benkler and colleagues mapped the US media ecosystem by who links to whom, and found the two sides were not mirror images. The left runs continuously into the centre, all of it orbiting the Washington Post, the New York Times, CNN and Politico. The right is anchored by Breitbart and Fox News, has almost no overlap with the centre, and has barely a centre-right at all. That asymmetry was the finding: asymmetric polarisation, not just polarisation. It is a claim about shape rather than about any number.

How to read it

Each circle is a news source, sized by how many other sources link to it. The Washington Post is the biggest because 5,100 distinct outlets cite it.

A line means one outlet linked to the other, and the more they link, the closer the layout pulls them. The whole dataset is links; everything else on the chart is inferred from them.

The colour is not the side the outlet takes: it is who shared it. Dark blue means at least 4:1 of the people tweeting its stories also retweeted Clinton; light blue 3:2; green roughly even; pink 3:2 Trump; red 4:1 Trump.

So position and colour come from different datasets. Where a node sits comes from hyperlinks between publishers; its colour comes from Twitter sharing by readers. Nothing on the figure says so.

Position is not data. A force-directed layout puts connected nodes near each other and pushes unconnected ones apart. There are no axes, and absolute position means nothing.

What is real is the clustering (who ends up next to whom) and the density of each group. Distance between two specific dots is not.

THE CRITIQUE

01 · Describe

A cloud of coloured points joined by many thin lines, with no axes, no scale and no gridlines. Some regions are dense to the point of being solid; others are sparse. Point size varies with how much each node is linked to.

02 · Analyse

The only data channel is topology: who connects to whom. The layout algorithm converts that into two spatial dimensions, and it is a choice: different algorithms, or the same one with a different random seed, give visibly different pictures of the same graph. Colour carries the group label, which is external to the network.

03 · Interpret

The claim is about structure: the communities are real, they are unequally dense, and one is more insulated than the other. Those are properties of the graph, which is why they survive the layout, but the picture makes them feel more precise than they are.

04 · Judge

Defensible when the claims stay topological and are backed by numbers, which Benkler’s are. Indefensible when a hairball is presented as evidence on its own. The honest test: could you state your finding as a statistic? If yes, show the statistic and the map. If no, the map is probably not showing it either.

THE RECREATION

Media Cloud’s link data is not openly downloadable, so this uses the dataset Benkler’s work descends from: Adamic and Glance’s 2005 map of US political blogs during the 2004 election. It is the original polarised-blogosphere network, and it is openly available.

Show the R code 
set.seed(3)
ggraph(g, layout = "fr") +
  geom_edge_link(alpha = .04, colour = "#3a3a34",
                 edge_width = .2, show.legend = FALSE) +
  geom_node_point(aes(colour = side, size = deg), alpha = .8) +
  scale_colour_manual(values = pal, name = NULL) +
  scale_size_continuous(range = c(.4, 4), guide = "none") +
  labs(title = "US political blogs, 2004",
       subtitle = "Force-directed layout. Two communities, few links across",
       caption = sprintf("n = %s blogs, %s links · Adamic & Glance (2005)",
                         format(gorder(g), big.mark = ","),
                         format(gsize(g), big.mark = ","))) +
  theme_void(base_family = dsvar_font()) +
  theme(plot.title = element_text(face = "bold", size = 12, hjust = 0),
        plot.subtitle = element_text(size = 9.5, colour = "#5a5a52", hjust = 0),
        plot.caption = element_text(size = 7.5, colour = "#7a7a70", hjust = 0),
        legend.position = "bottom")

1,222 blogs and 19,089 links: the largest weakly-connected component of the Adamic–Glance network, which is the part their paper analyses. Colour is the side each blog was coded to; node size is degree. Layout is Fruchterman–Reingold with a fixed seed.

TWO NODES DECIDED WHAT THIS FIGURE LOOKED LIKE

The file holds 1,224 linked blogs, and two of them (digital-democrat.blogspot.com and thelonedem.com) link to each other and to nothing else in the dataset. A force-directed layout has no attractive force between disconnected components, only repulsion, so that pair drifts until it hits the edge of the canvas and the other 1,222 blogs collapse into a blob in the opposite corner. The first version of this page shipped exactly that: one stray dot top-left, the entire argument squeezed into a fifth of the frame.

Nothing was wrong with the data and nothing errored. The fix is one line (keep the giant component), but notice what the line is: a decision about which nodes exist, taken because of how the drawing came out. That is a defensible choice here, and it is the same kind of choice as dropping an inconvenient case. The difference is only that this one is in the code above and in this box.

THE LAYOUT IS NOT THE DATA

make <- function(lay, lab) {
  ggraph(g, layout = lay) +
    geom_edge_link(alpha = .03, colour = "#3a3a34", edge_width = .15) +
    geom_node_point(aes(colour = side), size = .5, alpha = .8, show.legend = FALSE) +
    scale_colour_manual(values = pal) +
    labs(title = lab) +
    theme_void(base_family = dsvar_font()) +
    theme(plot.title = element_text(size = 9.5, hjust = .5, colour = "#3a3a34"))
}
library(patchwork)
make("fr", "Fruchterman–Reingold") + make("kk", "Kamada–Kawai") + make("drl", "DrL")

SAME GRAPH, THREE PICTURES

Identical nodes, identical edges, three algorithms. The clusters survive, which is reassuring and is why the topological claim holds. But the shapes, the apparent distance between the groups, and how dramatic the separation looks all change completely. A reader shown only one of these has no way to know which features are the data and which are the optimiser. Reporting the layout algorithm matters as much as reporting your axis limits.

asym <- g |>
  activate(edges) |>
  mutate(from_side = .N()$side[from], same = .N()$side[from] == .N()$side[to]) |>
  as_tibble() |>
  summarise(inward = mean(same), n = n(), .by = from_side)

ggplot(asym, aes(inward, fct_rev(from_side), colour = from_side)) +
  geom_segment(aes(xend = .5, yend = fct_rev(from_side)), linewidth = .5) +
  geom_point(size = 4) +
  geom_vline(xintercept = .5, colour = "#a5a199", linewidth = .4, linetype = "22") +
  scale_colour_manual(values = pal, guide = "none") +
  scale_x_continuous(labels = scales::label_percent(), limits = c(.5, 1)) +
  # Computed, not asserted: on the 2004 blogs the two sides are about equally
  # sealed. (An earlier title said "not equally sealed", which is Benkler's
  # finding on his own Media Cloud data, not this file's.)
  labs(title = sprintf("Each side keeps about %.0f%% of its links to itself",
                       100 * mean(asym$inward)),
       subtitle = "Share of each side's links that stay within its own side",
       x = "Links staying in-group", y = NULL,
       caption = sprintf("n = %s links · Adamic & Glance (2005). The dashed line is 50%%, i.e. no preference.",
                         format(gsize(g), big.mark = ",")))

The chart above states the whole argument as two numbers, in one sentence. The network map is still worth drawing: it shows shape and the outliers, and it persuades in a way a percentage cannot. But it should never be the only evidence, because a hairball is compatible with almost any claim, and the reader cannot check it. Draw the map to communicate; compute the statistic to know.
