Many analysts, one dataset

Twenty-nine teams were given the same data and the same question, and they did not get the same answer. This is the closest thing the social sciences have to a controlled experiment on the course’s central claim: that a dataset supports more than one defensible story. It is the reason this gallery exists.

THE ORIGINAL

“Results summary” from the Many Analysts, One Data Set project materials by Raphael Silberzahn, Eric L. Uhlmann, Daniel P. Martin et al., via osf.io/gvm2z, dedicated to the public domain under CC0 1.0. The authors’ own figure, not the journal’s typeset version, which is SAGE copyright.

Twenty-nine teams, 61 analysts, one dataset of football referee decisions, and one question: are referees more likely to give red cards to dark-skinned players than to light-skinned players? Every team chose its own analytic approach. The results were then collected and plotted together. All 29 sit on one odds-ratio axis, which means four have been converted from a Cohen’s d or a correlation, and the figure does not say which four. The asterisks against teams 21 and 27 mark something else: those two intervals run off the right edge, which is cut at 5.

How to read it

Each row is one analysis team, sorted by the size of the effect they found, not by team number, so the ordering is a finding rather than an index.

The dot is that team’s estimate and the line through it is their confidence interval.

The vertical reference line is “no effect”: an odds ratio of 1. A team whose interval crosses it did not find a significant effect.

The spread across rows is what matters. It comes from the analytic choices, not sampling error: every team had the identical data.

THE CRITIQUE

01 · Describe

A forest plot: one row per team, a point estimate with a horizontal interval, sorted ascending, with a vertical line at the null value. Some intervals cross the line and most do not. The x axis is an odds ratio.

02 · Analyse

The design decision that makes this work is sorting by estimate rather than by team. Sorted by team number it is noise; sorted by size it becomes a distribution you can see the shape of. The reference line does the same job as the diagonal on the replication page: it converts position into a judgement.

03 · Interpret

The claim is that analytic flexibility is a source of variation on the scale of the effect being studied. Note what it is not claiming: the teams mostly agree on direction. The disagreement is about magnitude and significance, which is precisely the range over which papers get published or not.

04 · Judge

It holds, and it is honest about a subtlety the headline usually loses: this is not a demonstration that the answer is unknowable. Most teams found a positive effect. What the figure shows is that the published answer would have depended on which team happened to write the paper.

tip <- arrow(length = unit(.055, "in"), type = "closed")

ggplot(plotted, aes(est, rank, colour = sig)) +
  geom_vline(xintercept = 1, colour = "#5a5a52", linewidth = .5, linetype = "22") +
  # Each interval is drawn as two segments out from the estimate, so the ends
  # that run off the axis can carry an arrowhead and the ends that do not can't.
  geom_segment(data = ~ filter(.x, !clip_lo), aes(xend = lo_draw, yend = rank), linewidth = .6) +
  geom_segment(data = ~ filter(.x, !clip_hi), aes(xend = hi_draw, yend = rank), linewidth = .6) +
  geom_segment(data = ~ filter(.x,  clip_lo), aes(xend = lo_draw, yend = rank), linewidth = .6, arrow = tip) +
  geom_segment(data = ~ filter(.x,  clip_hi), aes(xend = hi_draw, yend = rank), linewidth = .6, arrow = tip) +
  geom_point(aes(shape = source), size = 2, stroke = .9, fill = NA) +
  scale_colour_manual(values = c("Interval excludes 1" = "#1e7c50",
                                 "Interval includes 1" = "#a5a199"),
                      name = NULL) +
  scale_shape_manual(values = c("Reported as a ratio" = 16, "Converted from d or r" = 1),
                     name = NULL) +
  scale_y_continuous(breaks = plotted$rank, labels = paste("Team", plotted$team),
                     expand = expansion(add = .8)) +
  scale_x_log10(breaks = c(0.5, 0.75, 1, 1.5, 2, 3)) +
  coord_cartesian(xlim = XLIM) +
  guides(colour = guide_legend(order = 1), shape = guide_legend(order = 2)) +
  labs(title = "Same data, same question, 29 answers",
       subtitle = "Odds ratio for a dark-skinned player receiving a red card, by analysis team",
       x = "Odds ratio (log scale). 1 = no effect", y = NULL,
       caption = sprintf("n = %d teams, %d of them converted to an odds ratio from a d or an r. Arrowheads mark intervals that continue past the axis · Silberzahn et al. (2018)",
                         nrow(plotted), sum(plotted$derived))) +
  theme(axis.text.y = element_text(size = 7.5), legend.position = "bottom")

20 of 29 intervals exclude 1. Estimates run from 0.89 to 2.93, from slightly protective to nearly three times the odds. The four hollow points are the teams that reported a Cohen’s d or a correlation; we converted them, as the original does, and the values match the published figure to two decimals. Because the conversion is monotone and sends 0 to 1, it cannot move a team across the reference line: it changes where they sit, never which side they are on.

EVEN ASSEMBLING THE CHART REQUIRED A CHOICE

The teams did not report on a common scale. Twenty-five gave ratios, on which 1 means no effect; four gave a Cohen’s d or a correlation, on which 0 does. Putting all 29 on one chart means converting those four, and the formulas rest on an assumption the original teams never made: that behind the binary outcome there is a continuous, logistically distributed propensity to be shown a card. That is what lets a d become an odds ratio at all.

So the chart above cannot be assembled without an analytic choice, in a paper about analytic choices. We make the same choice the original makes, and get the same numbers. What we add is a visible seam (the converted teams are drawn hollow), so the reader can tell the authors’ reported values from arithmetic performed on their behalf. The alternative, plotting only the 25 and dropping four teams from a study whose entire subject is the variation across teams, is defensible too, and worse.

WHAT THE SORT IS DOING

Show the R code 
both <- bind_rows(
  plotted |> mutate(pos = team, how = "Ordered by team number"),
  plotted |> mutate(pos = rank, how = "Ordered by estimate")
) |> mutate(how = factor(how, c("Ordered by team number", "Ordered by estimate")))

ggplot(both, aes(est, pos)) +
  geom_vline(xintercept = 1, colour = "#5a5a52", linewidth = .4, linetype = "22") +
  geom_linerange(aes(xmin = lo_draw, xmax = hi_draw), colour = "#c2cdc7", linewidth = .5) +
  geom_point(colour = dsvar_accent(), size = 1.5) +
  facet_wrap(~how) +
  scale_x_log10() +
  coord_cartesian(xlim = XLIM) +
  labs(x = "Odds ratio (log scale)", y = NULL,
       title = "Identical estimates. One decision about row order.",
       caption = "n = 29 teams") +
  theme(axis.text.y = element_blank())

On the left the teams look like noise around a value; on the right you can see the shape of the disagreement, read off how many cross the line, and spot that the spread is asymmetric. Week 2 makes this point about bar charts. Here the sort is the difference between a table with dots on it and a finding.

WHAT WOULD HAVE BEEN PUBLISHED

Show the R code 
LV <- c("Significant positive", "No significant effect", "Significant negative")

verdicts <- effects |>
  mutate(verdict = factor(case_when(lo > 1 ~ LV[1], hi < 1 ~ LV[3], TRUE ~ LV[2]), LV),
         label = as.character(team),
         # The same order as the forest plot, folded into a grid that reads
         # left to right, top to bottom, smallest effect first. Keeping the
         # order means the grid can show *where* the nulls are, not just how
         # many — a grouped unit chart would throw that away.
         col =  (rank - 1) %%  10 + 1,
         row = -((rank - 1) %/% 10))

# ggplot 4 only draws a legend key for a level it has data for, so an empty
# category would silently vanish from the legend — which is the opposite of
# what this chart is for. One off-panel square gives the key something to draw
# and the coord clips it away.
ghost <- tibble(col = 99, row = 99, label = "", verdict = factor(LV[3], LV))

ggplot(bind_rows(verdicts, ghost), aes(col, row, fill = verdict)) +
  # No tile border: the gap is made by shrinking the tile, so it stays
  # transparent and the grid works on both the light and the dark site.
  geom_tile(width = .88, height = .88, colour = NA) +
  geom_text(aes(label = label, colour = verdict), show.legend = FALSE,
            size = 3.2, fontface = "bold") +
  scale_fill_manual(values = setNames(c("#1e7c50", "#a5a199", "#8c3a2b"), LV),
                    drop = FALSE, name = NULL) +
  scale_colour_manual(values = setNames(c("#ffffff", "#3a3a34", "#ffffff"), LV),
                      guide = "none") +
  coord_equal(xlim = c(0.4, 10.6), ylim = c(-2.6, 0.6), expand = FALSE) +
  labs(title = "The same study, written up 29 times",
       subtitle = "What each team would have reported, in the order they appear above, smallest effect first",
       caption = sprintf("%d of %d teams would have published a significant effect. None would have published the opposite · Silberzahn et al. (2018)",
                         sum(verdicts$verdict == LV[1]), nrow(verdicts))) +
  theme_dsvar(base_size = 11, grid = "none") +
  theme(axis.text = element_blank(), axis.title = element_blank(),
        axis.ticks = element_blank(), axis.line.x = element_blank(),
        legend.position = "bottom")

The forest plot answers how big. This chart answers what would have been concluded, which is the question the literature runs on, and it needs a different form because the outcome is a category and not a quantity. Two thirds of these parallel papers report an effect, one third report a null, and none report the reverse. The third key in the legend has nothing behind it on purpose: the absence of a category is a finding, and a chart that silently drops an empty category lets you assume the teams disagreed about direction. They never did; the argument was only ever about magnitude.

Keeping the estimate order pays off here. The nulls are not scattered: eight of the nine sit in the smallest third, and the ninth is team 27 at the far end, whose interval was so wide it could not rule out anything: a null for the opposite reason. Look too at what interrupts the run at the start. Teams 10, 4 and 11 are significant while their neighbours are not, and all three are converted teams whose reported intervals are extraordinarily narrow: team 4’s d ran from 0.1026 to 0.1031. Grouping the squares by verdict would have given the same 20 : 9 split and hidden every one of these.
