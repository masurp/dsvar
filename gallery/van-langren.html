Van Langren’s longitudes

Twelve estimates of how far Rome lies east of Toledo, on a single line. This graph is often called the first graph of statistical data, and it was drawn to win a royal grant. It works the way a strip plot still works: you see at once how far the estimates disagree. What it does not show is that every one of them is wrong.

THE ORIGINAL

Grados de la Longitud, from La Verdadera Longitud por Mar y Tierra by Michael Florent van Langren, Antwerp, 1644. Public domain (author died 1675); scan via Wikimedia Commons.

Finding longitude was the great unsolved problem of seventeenth-century navigation. Latitude you can read off the sun; longitude needs the time at a reference place, and there was no clock that kept it at sea. Van Langren, royal cosmographer to Philip IV of Spain, believed he had a method, using the way light falls on the mountains and craters of the Moon, and he spent more than twenty years asking the Spanish crown to pay for it. This graph is the case for paying. The book’s title is the argument: The true longitude, by sea and land.

How to read it

Toledo is zero. The scale is degrees of longitude east of Toledo, from 0 to 30, ticked every degree.

Each ring is one authority’s answer to the question “how far east is Rome?” Their name is written straight up above it, in Latin form: Iansonius is Jan Jansson, Ptolomeus is Ptolemy.

There are twelve answers, from 17.7° to 30.1°.

ROMA labels the cluster, not a value. It is set in a convenient gap and is neither an average nor van Langren’s own answer. See below.

The right answer is not on the graph. Nobody had it in 1644. Today’s figure is 16.5°, to the left of every ring.

THE CRITIQUE

01 · Describe

One horizontal scale from 0 to 30 degrees, with TOLEDO written up the left edge at zero. Twelve small markers sit on the scale between about 18 and 30, each with a name written vertically above it. The word ROMA is set in the gap between two clusters of markers. The title fills the empty left half. Nothing else: no second axis, no legend, no list of sources.

02 · Analyse

One continuous variable on one common scale, so position carries every value, and position is the channel people read most accurately. In today’s vocabulary it is a strip plot. The labels keep who said what, so it needs no table beside it. The scale starts at Toledo, a true zero for a distance, which makes the empty left half information rather than waste: every authority puts Rome at least 17 degrees away. The markers fall into two clusters, between 18 and 21 degrees and between 25 and 30.

03 · Interpret

The claim is that the experts disagree, by 12.4 degrees, about the distance between two of the best-known cities in Europe. At Toledo’s latitude that is about 1,060 km. The audience was a royal patron, and the unstated next step is the point: if Toledo to Rome is this uncertain, a ship’s position in the Atlantic is worse, and van Langren knew how to fix it.

04 · Judge

For its claim, close to perfect. A table makes the reader find the spread by subtracting; the line shows it before anyone reads a name. Its limit is the more useful lesson now. It shows variability and cannot show bias. Every estimate is too large, by 1.2 to 13.6 degrees, and the graph cannot say so, because a chart can only show error against a reference that is not on it.

THE RECREATION

The data is HistData’s digitisation of the graph. The marks are drawn the way the engraver drew them: a ring on the scale, with a smaller ring on top.

Show the R code 
ink <- p$ink

# The original is set in an old-style serif. Use the closest one installed.
serif <- c(intersect(c("Hoefler Text", "Baskerville", "Georgia"),
                     systemfonts::system_fonts()$family), "serif")[1]

# Names on neighbouring marks would print on top of each other, so nudge them
# apart until no two are closer than `gap` degrees, keeping each crowded run
# centred on the marks it labels. The engraver did the same by hand.
spread_out <- function(x, gap) {
  o <- order(x); y <- x[o]
  repeat {
    moved <- FALSE
    runs  <- cumsum(c(TRUE, diff(y) >= gap - 1e-9))
    for (r in unique(runs)) {
      i <- which(runs == r)
      if (length(i) < 2) next
      want <- mean(x[o][i]) + (seq_along(i) - (length(i) + 1) / 2) * gap
      if (any(abs(want - y[i]) > 1e-9)) { y[i] <- want; moved <- TRUE }
    }
    if (!moved) break
  }
  replace(x, o, y)
}

ticks  <- tibble(x = 0:30, len = if_else(x %% 5 == 0, .11, .07))
marks  <- tibble(x = c(0, langren$Longitude))      # Toledo gets a mark too
labels <- langren |> mutate(at = spread_out(Longitude, .5))

recreation <- ggplot() +
  annotate("segment", x = 0, xend = 30, y = 0, yend = 0, colour = ink, linewidth = 1.1) +
  geom_segment(data = ticks, aes(x = x, xend = x, y = 0, yend = -len),
               colour = ink, linewidth = .9) +
  annotate("text", x = c(10, 20, 30) - .35, y = -.16, label = c(10, 20, 30),
           family = serif, size = 5.4, colour = ink) +
  # each mark is a ring on the scale with a smaller ring on top, as engraved

  geom_point(data = marks, aes(x, .115), shape = 1, size = 2.2, stroke = 1.3, colour = ink) +

            angle = 90, hjust = 0, family = serif, fontface = "bold.italic",
            size = 5, colour = ink) +
  annotate("text", x = .05, y = .17, label = "TOLEDO.", angle = 90, hjust = 0,
           family = serif, size = 8.2, colour = ink) +

recreation

n = 12 determinations, as digitised in HistData::Langren1644. Drawn at the scan’s proportions, 595 × 151, with 0 and 30 where the engraving puts them, so the two can be compared directly. Names are spelled as HistData transcribes them (Jansonius where the engraver set Iansonius), and the title is in capitals where the engraver used small capitals.

HOW WE KNOW

The values. Nobody typed these in from a table, because van Langren never published one. Friendly, Valero-Mora and Ibáñez Ulargui digitised them from the graph itself for their 2010 paper, and they ship with the HistData package. The comparison above is the check: a misread value would show as a ring out of place.

What ROMA means. The word is easy to read as van Langren’s best estimate, set in the middle of the range. It is not. Friendly and colleagues found earlier versions of the graph, the oldest in a letter to the Archduchess Isabella from before March 1628, where ROMA is written in front of each authority’s name: every marker is “Rome, according to this person”. Combining several observations into one average was not yet an idea anyone had published. They date its first statement to 1635, seven years after that letter.

The right answer. Taking Toledo at 4.03° W and Rome at 12.5° E, the difference is 16.53°. That figure took more than a century after this graph to pin down, and it is the one number the critique needs that van Langren could not have had.

One added line turns a picture of disagreement into a picture of bias. Van Langren’s graph shows the estimates are spread out. This one shows they are spread out on the wrong side.

On a map

Show the R code 
romes <- langren |>
  mutate(lon = TOLEDO[["lon"]] + Longitude, lat = ROME[["lat"]],
         where = maps::map.where("world", lon, lat))
n_italy   <- sum(romes$where == "Italy", na.rm = TRUE)
n_sea     <- sum(is.na(romes$where))
n_balkans <- sum(romes$where %in% c("North Macedonia", "Bulgaria"))
stopifnot(n_italy + n_sea + n_balkans == nrow(romes))

cities <- tibble(name = c("Toledo", "Rome"),
                 lon = c(TOLEDO[["lon"]], ROME[["lon"]]),
                 lat = c(TOLEDO[["lat"]], ROME[["lat"]]))

# Names written straight up, as van Langren set them, nudged apart where two
# estimates sit closer than a line of type (spread_out() is from the
# recreation above). No name moves more than a tenth of a degree.
named <- romes |> mutate(at = spread_out(lon, .5))

# Each arrow stops a little short of its dot, so the head is not hidden under
# it. "Short" has to be measured along the direction the curve arrives from,
# not the straight line from Toledo: a curve of curvature k arrives turned by
# about 2·atan(k) from its chord. Worked on the drawn map, where a degree of
# longitude is cos(latitude) as wide as a degree of latitude.
CURVE <- .25
squash <- cos(mean(c(35.5, 46.5)) * pi / 180)
trips <- romes |>
  mutate(chord = atan2(lat - TOLEDO[["lat"]], (lon - TOLEDO[["lon"]]) * squash),
         arrive = chord + 2 * atan(CURVE),
         xend = lon - .24 * cos(arrive) / squash,
         yend = lat - .24 * sin(arrive))

ggplot() +
  geom_polygon(data = map_data("world"), aes(long, lat, group = group),
               fill = "#ece8de", colour = "#d6d0c2", linewidth = .2) +
  # One trip per estimate, as on a flow map: Toledo is where every one starts
  geom_curve(data = trips, aes(x = TOLEDO[["lon"]], y = TOLEDO[["lat"]],
                               xend = xend, yend = yend),
             curvature = CURVE, colour = dsvar_accent(), alpha = .35, linewidth = .3,
             arrow = arrow(length = unit(1.4, "mm"), type = "closed")) +
  geom_text(data = named, aes(at, lat + .4, label = Name), angle = 90, hjust = 0,
            family = dsvar_font(), size = 2.5, colour = p$ink_3) +
  geom_point(data = romes, aes(lon, lat), colour = dsvar_accent(), size = 2.6) +
  geom_point(data = cities, aes(lon, lat), colour = p$ink, size = 2.6, shape = 15) +
  geom_text(data = cities, aes(lon, lat, label = name), vjust = 1.9,
            family = dsvar_font(), fontface = "bold", size = 3.4, colour = p$ink) +
  coord_quickmap(xlim = c(-9.5, 29), ylim = c(35.5, 46.5), expand = FALSE) +
  labs(title = sprintf("Twelve Romes: %d in Italy, %d in the Adriatic, %d in the Balkans",
                       n_italy, n_sea, n_balkans),
       subtitle = "Each estimate measured east from Toledo and placed on Rome's latitude",
       x = NULL, y = NULL,
       caption = "Coastlines: the maps package.") +
  theme(axis.text = element_blank(), panel.grid.major = element_blank(),
        axis.line.x = element_blank(),
        panel.background = element_rect(fill = "#e3edf0", colour = NA))

The same numbers as distances on the ground, which is what they were for. Christoph Clavius taught in Rome, at the Collegio Romano, and his figure puts the city in North Macedonia.

A graph of many estimates of one quantity shows how much they disagree. It cannot show whether they are right, because the right answer is not one of the marks. That is still true: when 29 research teams analysed one dataset, the chart of their answers made the same argument van Langren’s did, and had the same missing line. See Many analysts, one dataset. Spread is visible; bias needs a reference, so if you have one, draw it.
