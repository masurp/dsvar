The PISA league table

Every three years PISA tests 15-year-olds in some eighty education systems, and every three years the results become a ranking. This is the US government’s 2022 table for mathematics. It is more careful than most league tables: it marks which differences are real. But it marks them against only one country, and it prints a precise order that the data does not have.

THE ORIGINAL

Table M1. Average scores and difference from U.S. average score of 15-year-old students on the PISA mathematics literacy scale, by education system: 2022, from Highlights of U.S. PISA 2022 Results Web Report (NCES 2023-115 and 2024-103). National Center for Education Statistics, U.S. Department of Education. Data: OECD, PISA 2022. Public domain (a U.S. federal work; IES site policy). Captured from the interactive page in its default view, 7 October 2026.

PISA, the OECD’s Programme for International Student Assessment, tests a sample of 15-year-olds in each system every three years; 2022’s main subject was mathematics. The OECD publishes its own report, and each country publishes its own reading of it. This is the American one, so its reference point is the United States.

How to read it

Sorted by average score, highest first, running down the left column and then the right. The place in the list is never printed, but it is what everyone reads.

▲ and ▼ mark systems significantly above or below the United States; ◆ marks the ones that are not significantly different from it. Nothing says whether two other systems differ from each other.

! and !! mark a difference too imprecise to trust (its standard error is 30–50 per cent, or more than half, of the difference).

¹ and ² mark samples that cover only 50–75 per cent, or under half, of the country’s 15-year-olds. The rest are out of school or out of reach.

Italic names are not OECD members. The score has no natural zero: the scale was set in 2003 so that OECD countries averaged 500.

THE CRITIQUE

01 · Describe

A ranked list of 81 education systems in two columns, from Singapore at 575 to Cambodia at 336, with the OECD average on top. Each row gives an average score, its difference from the United States and a symbol. The US row, 34th from the top, is navy with a flag. Footnote marks flag unstable differences and thin samples.

02 · Analyse

A table, but its order makes it a chart: position in the list encodes rank, and rank is the only thing it encodes visually. The numbers carry the sizes of the gaps, but only where a gap is significant: the twelve ◆ rows get no number at all. The symbols carry the uncertainty, and only along one axis: every system against the US. The table cannot say whether any of the twelve ◆ rows differ from each other.

03 · Interpret

For its audience the claim is: the United States is middling. Below 25 systems, above 43, indistinguishable from 12, and level with the OECD average. What a reader carries away is shorter: 34th.

04 · Judge

Better than most league tables, which print a rank and nothing else. Its weakness is the one it shares with them: the order is more precise than the evidence. On the same significance tests the US could be anywhere from 26th to 38th, and only 1 system in the table, Singapore, holds a place that is certain. The coverage footnotes deserve more than a superscript. Where under half of 15-year-olds are in the sample, the score describes the ones still in school.

THE RECREATION

A table is a chart that happens to use text, so the recreation is a ggplot too: every word below is a geom_text() placed where the original puts it, and every symbol is a point.

cols <- tibble(col = 1:2, name_x = c(124, 1172), score_x = c(668, 1700),
               diff_x = c(1000, 2032), mark_x = c(1036, 2072))

# The OECD average leads the left column, then the 81 systems in order.
rows <- bind_rows(
  tibble(system = "OECD average", oecd = 1, coverage_note = 0, caution = 0,
         score = round(oecd_average), diff = NA, vs_us = "not different", bold = TRUE),
  pisa |> transmute(system, oecd, coverage_note, caution, score = round(mean),
                    diff = if_else(code == "USA", NA, round(mean - us$mean)),
                    vs_us, bold = FALSE)) |>
  mutate(slot = row_number(), col = if_else(slot <= 41, 1, 2),
         i = if_else(col == 1, slot, slot - 41), y = H - row_y(i),
         is_us = system == "United States",
         label = paste0(system, case_when(coverage_note == 1 ~ " ¹",
                                          coverage_note == 2 ~ " ²", TRUE ~ "")),

  left_join(cols, by = "col")

marks <- rows |> filter(!is_us) |>

HOW WE KNOW

The numbers. The table is drawn in the browser from NCES’s data service, the same service behind its PISA Data Explorer. Asking it for the 2022 mathematics means, and for every pairwise comparison between the 81 systems, returns exactly the published table: the same scores to the unit, and the same 25, 43 and 12 against the US.

What we checked first. The page also ships an older cached copy of the comparisons, and that one does not match: it marks France and Spain as significantly above the US, where the table, and the live service, say they are not. An exhibit about how fragile a ranking is should not rest on the wrong file, so the cached copy is not used.

The footnote marks are drawn by the page’s stylesheet, not written in its text, so they were transcribed by eye from the rendered table: 13 systems marked ¹, 2 marked ², and 4 differences marked ! or !!.

The rank ranges below need no new statistics, only the table’s own tests applied to every pair. A system is certainly below every system that is significantly higher than it, and certainly above every system it is significantly higher than. Everything in between is a place it could hold.

         who = factor(case_when(code == "USA" ~ "United States",

Why not bars

Show the R code 
top <- pisa |> filter(place <= 10 | code == "USA") |>
  mutate(system = fct_reorder(system, mean), us = code == "USA")

bars <- ggplot(top, aes(mean, system, fill = us)) +
  geom_col(width = .7) +
  scale_fill_manual(values = c(dsvar_accent(), "#b3122e"), guide = "none") +
  labs(title = "Bars from zero", subtitle = "The lengths look alike, and mean nothing",
       x = NULL, y = NULL) +
  theme(panel.grid.major.y = element_blank())

dots <- ggplot(top, aes(mean, system, colour = us)) +
  geom_point(size = 3) +
  scale_colour_manual(values = c(dsvar_accent(), "#b3122e"), guide = "none") +
  labs(title = "Positions on the scale", subtitle = "The gaps, in the units PISA reports",
       x = NULL, y = NULL) +
  theme(panel.grid.major.y = element_blank(), axis.text.y = element_blank())

bars | dots

A bar’s length is a claim about a ratio: twice as long, twice as much. PISA’s zero is not no mathematics; the scale was set so that OECD countries averaged 500, and a score of 575 is not 24 per cent more mathematics than 465. Position makes no such claim, which is why the left panel is the wrong chart and the right one is not.

A ranking prints one place per row, and the data supports a range. The NCES table is honest about the gaps it tests and silent about the rest, which is what every league table does with less care. Before you sort anything, ask which differences between neighbours are real, and draw the answer, not just the order.
