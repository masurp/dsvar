Nightingale’s rose diagram

A chart made to change a government’s mind, and it did. It is also built on an encoding the course spends a week warning you about, which makes it worth an hour rather than a slide.

THE ORIGINAL

Diagram of the Causes of Mortality in the Army in the East by Florence Nightingale, 1858, in Notes on Matters Affecting the Health, Efficiency and Hospital Administration of the British Army. Public domain (author died 1910); scan via Wikimedia Commons.

Florence Nightingale’s Diagram of the Causes of Mortality in the Army in the East, drawn in 1858 for a royal commission on the health of the British army. Two roses, one per year of the Crimean War, each divided into twelve months running clockwise.

How to read it

Each wedge is one month, twelve to a circle, going clockwise. The right-hand rose is the first year of the war, the left-hand one the second.

Blue is death from preventable disease: cholera, typhus, dysentery. It is almost all of the area.

Red is death from wounds. Being shot at was a small part of what killed the army.

Black is everything else.

The wedges radiate from a common centre, so the quantity is the area of the wedge, not its radius. Most recreations get this wrong (below).

THE CRITIQUE

01 · Describe

Two circular diagrams, each cut into twelve wedges of equal angle. Each wedge is filled in up to a different radius, in three colours layered from the centre. A block of hand-set text explains the construction, because without it the reader cannot know what the radius means.

02 · Analyse

Time is on angle, which is a poor channel for order: you cannot see at a glance which month came first. Quantity is on area, which Cleveland and McGill rank near the bottom for accuracy. Almost every encoding choice here is one the course would talk you out of, and the chart still works.

03 · Interpret

The claim is not “disease was seasonal” but “disease killed far more of this army than the enemy did, and it fell when we cleaned the hospitals.” For that claim you do not need to read a value. You need to see one colour swamp the others, and then shrink.

04 · Judge

It survives, because the claim it makes is one that area can carry: a ratio so large that even an inaccurate channel cannot blur it. Copy the form for a comparison of similar-sized quantities and it collapses immediately. An encoding is only as bad as the claim it is asked to support.

THE RECREATION

Show the R code 
# Nightingale's colours, sampled from the lithograph rather than invented.
causes <- c("Preventable disease" = "#7FA8C9",
            "Wounds"              = "#B0413E",
            "Other causes"        = "#3a3a34")

ggplot(long, aes(Month, rate, fill = cause)) +
  # position = "identity" matters: the three causes are drawn OVER one another
  # from the centre, exactly as Nightingale drew them, not stacked.
  geom_col(width = 1, position = "identity", alpha = .85,
           colour = "white", linewidth = .2) +
  coord_polar(start = 0) +
  facet_wrap(~period) +
  scale_fill_manual(values = causes, name = NULL) +
  labs(x = NULL, y = NULL,
       title = "Disease killed far more of the army than wounds did",
       subtitle = "Annual death rate per 1,000, by month and cause, Crimean War",
       caption = "n = 24 months · Nightingale (1858), via HistData") +
  theme_dsvar(base_size = 10, grid = "none") +
  theme(axis.text.y = element_blank(), legend.position = "bottom")

This recreation is less faithful than it looks: geom_col in polar coordinates maps the value to radius, whereas Nightingale mapped it to area. The next section is about that difference.

THE TRAP EVERY RECREATION FALLS INTO

RADIUS IS NOT AREA

A wedge’s area grows with the square of its radius. Nightingale knew this and scaled her wedges so that area was proportional to deaths; she says so in the note on the plate. coord_polar() does not: it maps your value straight onto radius, so a month with four times the deaths is drawn with four times the radius and sixteen times the area. Every quick ggplot recreation of this chart, including the one above, exaggerates the peaks. The fix is one line.

Show the R code 
# Facets sort alphabetically unless told otherwise, which silently put "area"
# on the left and made the caption below wrong the first time this rendered.
hows <- c("Value on radius\n(ggplot's default)", "Value on area\n(what Nightingale drew)")
compare <- bind_rows(
  long |> filter(cause == "Preventable disease") |> mutate(r = rate,       how = hows[1]),
  long |> filter(cause == "Preventable disease") |> mutate(r = sqrt(rate), how = hows[2])
) |>
  mutate(how = factor(how, levels = hows)) |>
  # Each panel is scaled to its own maximum. facet_grid shares one radial
  # scale, and sqrt(1023) is 32, so the area version rendered as a dot. What is
  # being compared here is the SHAPE — how the months relate to each other —
  # not the absolute size, and the caption says so.
  mutate(r = r / max(r), .by = c(period, how))

ggplot(compare, aes(Month, r)) +
  geom_col(width = 1, fill = causes[["Preventable disease"]], alpha = .85,
           colour = "white", linewidth = .2) +
  coord_polar() +
  facet_grid(period ~ how, switch = "y") +
  labs(x = NULL, y = NULL,
       title = "The same deaths, drawn two ways",
       subtitle = "Preventable disease only, both years",
       caption = "Taking the square root before plotting puts the quantity back on area, where Nightingale had it.") +
  theme_dsvar(base_size = 9, grid = "none") +
  theme(axis.text.y = element_blank(),
        strip.text.y.left = element_text(angle = 90, size = 7.5),
        strip.text.x = element_text(size = 8.5))

Left: what you get by default. Right: the same numbers with sqrt() applied, so area carries the quantity. Each panel is scaled to its own maximum, so compare the shapes rather than the sizes: January’s wedge dominates its neighbours far more on the left than it should. Absolute magnitudes across the two years are in the chart above and the one below.

THE SAME DATA, UNROLLED

Show the R code 
ggplot(long, aes(Date, rate, fill = cause)) +
  geom_area(alpha = .9) +
  annotate("segment", x = as.Date("1855-03-01"), xend = as.Date("1855-03-01"),
           y = 0, yend = 1100, colour = "#5a5a52", linewidth = .4, linetype = "22") +
  annotate("text", x = as.Date("1855-03-20"), y = 1050, hjust = 0, size = 3,
           colour = "#3a3a34", family = dsvar_font(),
           label = "Sanitary Commission arrives") +
  scale_fill_manual(values = causes, name = NULL) +
  labs(x = NULL, y = "Deaths per 1,000 per year",
       title = "The same 24 months on a time axis",
       subtitle = "Readable, orderable, and much easier to argue with",
       caption = "n = 24 months · Nightingale (1858), via HistData") +
  theme(legend.position = "bottom")

This version is better on every measure the course usually cares about: time on position, quantity on length, the turning point annotated. It is also the version that would not have been printed, passed around a commission, or remembered for 160 years. Nightingale was not choosing between accurate and beautiful but between a chart that was read and one that was not.
