Minard’s march on Moscow

Six variables in one figure, none of them a chart type you could pick from a menu. Tufte called it the best statistical graphic ever drawn. It is the course’s strongest argument for composing a figure rather than choosing one.

THE ORIGINAL

Carte figurative des pertes successives en hommes de l’Armée Française dans la campagne de Russie 1812–1813 by Charles Joseph Minard, 1869. Public domain (author died 1870); scan via Wikimedia Commons.

How to read it

The tan band is the Grande Armée marching east, from the Niemen river on the left to Moscow on the right, in the summer of 1812.

The black band is the same army retreating west, back the way it came, through the winter.

The width of a band is the number of men still alive. 422,000 set out and 10,000 came back. Nothing else on the map encodes that: the collapse is the narrowing.

The army is not one band but three. It splits into separate columns that march apart and rejoin, so at any point you may be looking at a branch rather than the whole force.

The names along the route are towns and rivers. Each place where the black band suddenly thins is a river crossing.

The panel underneath is the temperature during the retreat, lining up with the map above by longitude. It is in degrees Réaumur, not Celsius.

There is no legend, no scale bar and no axis on the map itself. Minard explains all of this in the French text at the top, which is one reason a key is needed here.

THE CRITIQUE

01 · Describe

A band crosses a map from left to right and back again. Going out it is tan and wide; coming back it is black and much thinner, and it thins further at each branch. Below the map sits a separate line plot falling from zero to −30. City names are lettered along the route. There is no legend and no vertical axis on the map.

02 · Analyse

Six variables, on five channels. Longitude and latitude on position; army size on band width; direction of travel on colour, as a two-value split; date and temperature in the panel below, tied back to the map by shared longitude. Width is the load-bearing channel, and it is used for the one quantity that matters most.

03 · Interpret

The claim is that the army was destroyed, and the figure says where, when, and in what cold. It is not arguing that the cold caused the losses: the band is already a third of its width before the temperature panel begins. The graphic lets you notice that yourself, which is a stronger move than asserting it.

04 · Judge

It works, and it is not a template. The variables are coupled (a place, a time, and a number that changes because of both), so composing them into one figure buys something that six separate charts would not. But it carries no uncertainty at all, its geography is loose, and you cannot read a value off it. It earns those omissions; most charts that imitate its density do not.

THE RECREATION

This is an attempt, not a facsimile. The aim is to get the encoding right, six variables in one figure, without the hand lettering, the French annotations, the river-crossing branches or the paper. Michael Friendly calls reproducing this “Minard’s Challenge”, and the point of the challenge was always the grammar rather than the calligraphy.

Show the R code 
# Minard's two inks: tan out, black back.
ink  <- c(A = "#D9BC7E", R = "#332B23")
xlim <- c(23.6, 38.2)

march <- ggplot(troops, aes(long, lat)) +
  # group must combine direction AND group: the numbering restarts for the
  # retreat, so `group = group` silently joins the advance to the retreat.
  geom_path(aes(linewidth = survivors, colour = direction,
                group = interaction(direction, group)),
            lineend = "round", linejoin = "round") +
  geom_point(data = cities, size = 1, colour = "#8C1C13") +
  ggrepel::geom_text_repel(data = cities, aes(label = city),
                           size = 2.7, colour = "#8C1C13", family = dsvar_font(),
                           seed = 7, box.padding = 0.5, point.padding = 0.25,
                           max.overlaps = Inf, force = 6, max.iter = 20000,
                           min.segment.length = 0.25, segment.size = 0.2,
                           segment.colour = "#B08A84",
                           bg.color = "#faf8f4", bg.r = 0.12) +
  # Width is proportional to survivors and the scale starts at zero, which is
  # what makes the collapse readable. The 0.45 floor is a compromise: see below.
  scale_linewidth(range = c(0.45, 12), limits = c(0, max(troops$survivors))) +
  scale_colour_manual(values = ink) +
  coord_cartesian(xlim = xlim, ylim = c(53.8, 56.15)) +
  theme_void(base_family = dsvar_font()) +
  theme(legend.position = "none")

# Minard's thermometer is in degrees REAUMUR, not Celsius. See the note below.
temp_panel <- ggplot(temps, aes(long, temp)) +
  geom_line(colour = ink[["R"]], linewidth = 0.5) +
  geom_point(colour = ink[["R"]], size = 1.3) +
  geom_text(aes(label = paste0(temp, "°")), vjust = -1.1, size = 2.7,
            colour = ink[["R"]], family = dsvar_font()) +
  geom_text(aes(label = ifelse(is.na(date), "", date)), vjust = 2.1, size = 2.4,
            colour = "#7a7a70", family = dsvar_font()) +
  scale_y_continuous(breaks = c(0, -10, -20, -30)) +
  coord_cartesian(xlim = xlim, ylim = c(-34, 6)) +
  labs(y = "°Réaumur, on the retreat", x = NULL) +
  theme_dsvar(base_size = 9, grid = "y") +
  theme(axis.text.x = element_blank(), axis.line.x = element_blank(),
        axis.title.y = element_text(size = 7.5))

march / temp_panel + plot_layout(heights = c(2.7, 1))

Survivors, route and retreat temperatures of the Grande Armée, 1812–1813. n = 51 route points, 20 cities, 9 temperature readings. Data digitised by Leland Wilkinson for The Grammar of Graphics, distributed in the HistData package and vendored into this repo as CSV.

FOUR THINGS THAT BIT

1 · THE UNITS ARE NOT CELSIUS

Minard.temp$temp is documented only as “Temperature”. The obvious reading is Celsius, and it is wrong: Minard’s thermometer is Réaumur, a scale where water boils at 80°. His −30° is −37.5 °C, so calling it Celsius understates the cold by a quarter. Nothing in the data says so; only the original does, where Minard writes it on the chart. A column with no units is a column you do not yet understand.

2 · GROUP IS NOT WHAT YOU THINK

The group column numbers 1–3 for the advance and then starts again at 1 for the retreat. Mapping group = group therefore joins the end of each advance to the start of the unrelated retreat, drawing three phantom bands across the map. It looks like a rendering glitch rather than a data error, which is why it is worth meeting once. The fix is group = interaction(direction, group).

3 · THE HEADLINE NUMBERS ARE SUMS, NOT THE WIDEST BAND

The famous figures are 422,000 out and 10,000 back, and neither appears in any single row of the data. The widest advance band is 340,000; read that as the army and you understate it by a fifth. 422,000 is the three advance columns added at the Niemen; 10,000 is the two retreat columns that get back there, since the third stops at longitude 28.3 and never reaches the river. Both reconcile exactly once you sum the right branches, which is how you know you have understood the structure.

4 · PROPORTIONAL WIDTH HAS A FLOOR

Minard’s bands are proportional to the number of men. But 4,000 survivors is 1.2% of the 340,000 who set out, so at any sensible size for the widest band the thinnest one is less than a pixel and disappears. We set a floor of 0.45, so the last stretch is drawn slightly wider than it should be: a small but real departure from proportionality. Minard had the same problem and solved it with an engraver.

WHAT THE COMPOSITION BUYS

Here is the same headline number, the army’s size, as a chart you would reach for. It is more precise than Minard on the one variable it shows, and it has lost the argument.

Show the R code 
troops |>
  mutate(leg = if_else(direction == "A", "Advance", "Retreat")) |>
  ggplot(aes(long, survivors, colour = leg,
             group = interaction(direction, group))) +
  geom_line(linewidth = .8) +
  scale_colour_manual(values = c(Advance = "#B8912F", Retreat = "#332B23")) +
  scale_y_continuous(labels = scales::label_comma()) +
  labs(title = "The same collapse, as a chart you would reach for",
       subtitle = "Surviving troops against longitude. Readable, precise, and no longer about a place",
       x = "Longitude", y = NULL, colour = NULL,
       caption = "n = 51 route points · Minard (1869), digitised by Wilkinson")

LOOK AT THE RETREAT LINE AGAIN

It rises. Plotted against longitude, the retreat runs east to west, so it has to be read right to left. Read the way everyone reads a line chart, it shows an army growing from 4,000 to 100,000. The information is all still there and the chart is not lying; it has dropped the one channel, direction, that made the original impossible to misread.

This is the mirror image of the warming-stripes lesson. There, the plain chart was the one that could be checked and the famous graphic was the one that landed. Here the famous graphic is the one carrying more information, and the plain chart is the reduction. The moral is neither “be like Minard” nor “be plain”: the form follows the claim, and you have to know what your claim is before you can choose.
