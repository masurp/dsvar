Pandemic trajectories on a log scale

Two decisions, both arguable, both argued about at the time: put deaths on a log axis, and start every country’s clock at its own tenth death rather than on a shared calendar date. Together they turned an unreadable tangle into the chart a lot of people used to think about 2020.

THE ORIGINAL

“Coronavirus deaths in Italy, Spain and the US are increasing more rapidly than they did in China”. FT graphic by John Burn-Murdoch, Financial Times, data updated 26 March 2020. © The Financial Times Limited. The FT made its coronavirus charts free to read throughout the pandemic; the graphics remain FT copyright. Reproduced here at reduced resolution as a quotation for criticism and review — see ORIGINALS.md.

John Burn-Murdoch’s trajectory charts ran daily in the Financial Times through 2020 and were among the most widely reproduced graphics of the pandemic.

How to read it

Each line is one country, and the vertical axis is cumulative deaths: a running total, so it can only go up.

The horizontal axis is not calendar time. Day 0 is the day that country passed its tenth death, so outbreaks that began months apart can be laid on top of each other.

The vertical axis is logarithmic. Equal vertical steps are equal multiplications: 10 to 100 is the same distance as 100 to 1,000.

So a straight line means constant doubling, and the slope is the growth rate. Flattening means the rate is falling, not that deaths have stopped.

THE CRITIQUE

01 · Describe

A line chart of a few dozen series, each labelled at its end rather than in a legend. The vertical axis is unevenly spaced and labelled in powers of ten. Faint straight guide lines run diagonally across the plot, annotated with doubling times.

02 · Analyse

Two transformations do the work. The log axis turns exponential growth, which is unreadable on a linear scale, into slope, which people read well. The alignment removes the biggest confound: countries were at different points in their outbreak. Direct labels instead of a legend keep forty series legible.

03 · Interpret

The claim is about rate, not level: given a comparable starting point, some countries bent their curve and others did not. That is a much narrower claim than “country A did worse than country B”, and the chart is careful not to make the wider one.

04 · Judge

It holds, and the criticism it attracted was fair anyway. On a log axis a catastrophe and a disaster look similar, and “flattening” reads as good news when deaths are still climbing. The FT’s answer was to label the axis loudly, draw the doubling guides, and keep publishing linear versions alongside. A transform with this much effect has to be taught on the chart itself.

THE RECREATION

Show the R code 
# The doubling guides: on a log axis constant doubling is a straight line, so
# these are the reference the eye actually measures slope against.
guides <- expand_grid(days = c(2, 3, 7), day = 0:120) |>
  mutate(total_deaths = 10 * 2^(day / days),
         label = paste0("doubles every ", days, " days")) |>
  filter(total_deaths <= 1e5)

ends <- aligned |> slice_max(day, n = 1, by = country)

ggplot(aligned, aes(day, total_deaths, group = country)) +
  geom_line(data = guides, aes(group = label), colour = "#c9c4b8",
            linewidth = .35, linetype = "22") +
  geom_line(aes(colour = country %in% focus), linewidth = .7, alpha = .9) +
  ggrepel::geom_text_repel(data = filter(ends, country %in% focus),
                           aes(label = country), size = 2.8, hjust = 0,
                           family = dsvar_font(), seed = 2, direction = "y",
                           nudge_x = 3, segment.size = .2,
                           bg.color = "#faf8f4", bg.r = .12) +
  scale_colour_manual(values = c(`TRUE` = dsvar_accent(), `FALSE` = "#c2cdc7"),
                      guide = "none") +
  scale_y_log10(labels = scales::label_comma()) +
  coord_cartesian(xlim = c(0, 135), ylim = c(10, 1e5)) +
  labs(title = "Same starting point, very different slopes",
       subtitle = "Cumulative deaths on a log axis, aligned at each country's 10th death",
       x = "Days since the 10th death", y = "Cumulative deaths (log scale)",
       caption = sprintf("n = %d countries, 2020 · WHO via Our World in Data (CC BY 4.0)",
                         length(unique(aligned$country))))

THE TWO DECISIONS, TAKEN APART

Each panel changes exactly one thing from the chart above.

Show the R code 
cal <- cov |> filter(!is.na(total_deaths), total_deaths >= 10) |>
  mutate(day = as.numeric(date - as.Date("2020-01-01")))

grid4 <- bind_rows(
  cal     |> mutate(t = "Calendar date", s = "Linear"),
  cal     |> mutate(t = "Calendar date", s = "Log"),
  aligned |> mutate(t = "Aligned at 10th death", s = "Linear"),
  aligned |> mutate(t = "Aligned at 10th death", s = "Log")
) |>
  mutate(t = factor(t, c("Calendar date", "Aligned at 10th death")),
         s = factor(s, c("Linear", "Log")))

# One plot per y-transform, because a single facetted plot cannot carry two
# different scales — the mistake that produced two identical panels on the
# Gapminder page.
mk <- function(scale_lab) {
  g <- ggplot(filter(grid4, s == scale_lab), aes(day, total_deaths, group = country)) +
    geom_line(colour = dsvar_accent(), alpha = .55, linewidth = .5) +
    facet_wrap(~t, scales = "free_x") +
    labs(x = NULL, y = paste0("Cumulative deaths (", tolower(scale_lab), ")"),
         title = paste(scale_lab, "vertical axis"))
  if (scale_lab == "Log") g + scale_y_log10(labels = scales::label_comma()) else
    g + scale_y_continuous(labels = scales::label_comma())
}

library(patchwork)
mk("Linear") / mk("Log")

The bottom-right panel is the only one you can read, and it took both decisions to get there. The chart everyone remembers is not a neutral view of the numbers: it is two strong transformations, chosen because the raw version says nothing. Every one of those choices was available to someone who wanted a different answer.

WHAT THE LOG AXIS COSTS

Show the R code 
three <- aligned |> filter(country %in% c("United States", "Germany", "South Korea"))

lin <- ggplot(three, aes(day, total_deaths, colour = country)) +
  geom_line(linewidth = .8) +
  scale_colour_manual(values = dsvar_cat[1:3], name = NULL) +
  scale_y_continuous(labels = scales::label_comma()) +
  labs(x = "Days since 10th death", y = NULL, title = "Linear") +
  theme(legend.position = "bottom")

lg <- lin + scale_y_log10(labels = scales::label_comma()) +
  labs(title = "Log")

lin + lg

Same three countries, same 120 days. On the right the three lines look like variations on a theme. On the left one of them is an order of magnitude above the others. Both are true; only one of them feels like 300,000 people.
