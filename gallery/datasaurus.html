The Datasaurus dozen

Thirteen datasets with the same mean, the same standard deviation and the same correlation, to two decimal places. One of them is a dinosaur. It is the most efficient argument ever made for plotting your data before you summarise it.

THE ORIGINAL

“Same Stats, Different Graphs” by Justin Matejka and George Fitzmaurice, Autodesk Research, CHI ’17. Copyright Autodesk Research, reproduced for criticism and review under the Dutch citation right (Auteurswet art. 15a). The underlying data is separately MIT licensed, in the datasauRus R package.

This is the figure Justin Matejka and George Fitzmaurice use to set up their argument. On the left is Anscombe’s quartet (1973): four sets of eleven points with the same means, standard deviations, correlation and regression line, which look nothing alike. On the right are four datasets with matching statistics that look like nothing in particular. Their point is that Anscombe’s four are rare. Datasets with the same statistics are easy to make; datasets with the same statistics and clearly different shapes are not. The rest of their paper is a method for making them on demand, which is where the dinosaur comes from.

How to read it

Each panel is a complete dataset. They are different datasets, not different views of one.

Within each quartet the summary statistics match: the mean and standard deviation of x and of y, and the correlation between them.

The grey line is the same in every panel: the least-squares fit, which the matching statistics fix in place.

The ticks carry no numbers. Only the shapes are there to compare. The green tick and the red cross are the authors’ verdict: one quartet makes the point, the other does not.

THE RECREATION

The left half of the original, from datasets::anscombe, which ships with R. The axes are measured off the original: both run from 2, ticked every 2.

Show the R code 
q_stats <- quartet |>
  group_by(set) |>
  summarise(mx = mean(x), my = mean(y), sx = sd(x), sy = sd(y), r = cor(x, y))

n = 11 points per dataset. All four have a mean x of 9, a mean y of 7.5, a correlation of 0.82 and the same fitted line, y = 3 + 0.5x, computed here rather than quoted. Anscombe built them by hand. The right half of the original, the “unstructured” quartet, is not recreated: this page has the data for Anscombe’s four and for the dozen below, but not for those.

FROM FOUR TO THIRTEEN

Anscombe’s four took craft. Matejka and Fitzmaurice automated it, starting from Alberto Cairo’s “Datasaurus”, a scatterplot shaped like a dinosaur with unremarkable summary statistics. Their method is simulated annealing: nudge points at random, keep a nudge if it moves the shape towards a target while holding the statistics fixed, repeat. Twelve targets later, the dinosaur has a dozen siblings.

Show the R code 
ggplot(dino, aes(x, y)) +
  geom_point(colour = dsvar_accent(), alpha = .65, size = .8) +
  facet_wrap(~dataset, ncol = 5) +
  coord_equal() +
  labs(title = "Thirteen datasets. Same mean, same SD, same correlation.",
       subtitle = "Every panel: 142 points, identical summary statistics to two decimal places",
       x = NULL, y = NULL,
       caption = "n = 142 per dataset · Matejka & Fitzmaurice (2017), via datasauRus") +
  theme_dsvar(base_size = 9, grid = "none") +
  theme(axis.text = element_blank())

THE CLAIM, CHECKED

The page above asserts the statistics are identical. That is exactly the kind of claim this course says to verify rather than repeat, so here it is computed.

Show the R code 
stats <- dino |>
  group_by(dataset) |>
  summarise(mean_x = mean(x), mean_y = mean(y),
            sd_x = sd(x), sd_y = sd(y), r = cor(x, y), .groups = "drop")

rounded <- stats |> mutate(across(where(is.numeric), \(v) round(v, 2)))
identical_to_2dp <- rounded |> select(-dataset) |> distinct() |> nrow() == 1
spread <- stats |> summarise(across(where(is.numeric), \(v) max(v) - min(v)))

All thirteen agree to two decimal places: FALSE. At full precision they differ by at most 0.01 on any of the five statistics: the annealing gets close, not exact, and rounding does the rest.

WHAT A SUMMARY WOULD HAVE TOLD YOU

Show the R code 
ggplot(dino, aes(dataset, y)) +
  geom_boxplot(fill = "#dfe6e2", colour = "#5a5a52", linewidth = .35,
               outlier.size = .7) +
  labs(x = NULL, y = "y",
       title = "The same thirteen datasets, as boxplots",
       subtitle = "A dinosaur, a star and a bullseye, rendered indistinguishable",
       caption = "n = 142 per dataset") +
  theme(axis.text.x = element_text(angle = 35, hjust = 1, size = 7))

Boxplots are not the villain here: they do what they were designed to do, which is to throw away the shape and keep the quartiles. The mistake is asking a summary to tell you whether you need to look, because you cannot know a summary is sufficient without first looking at what it summarised.

SHOWING THE SHAPE INSTEAD

Show the R code 
ggplot(dino, aes(y, after_stat(density))) +
  geom_density(fill = dsvar_accent(), colour = NA, alpha = .8, bw = 3) +
  facet_wrap(~dataset, ncol = 5, scales = "free_y") +
  labs(x = "y", y = NULL,
       title = "The marginal distribution of y, per dataset",
       subtitle = "One number cannot say this, and one boxplot chose not to",
       caption = "n = 142 per dataset · bandwidth fixed at 3 so the panels are comparable") +
  theme_dsvar(base_size = 9, grid = "none") +
  theme(axis.text.y = element_blank())

Even the one-dimensional distribution separates them, once it is drawn rather than summarised. The bandwidth is fixed across panels on purpose: letting each panel pick its own would make them look more alike than they are.

SOURCES

  • Original: Matejka, J., & Fitzmaurice, G. (2017). Same stats, different graphs: Generating datasets with varied appearance and identical statistics through simulated annealing. Proceedings of the 2017 CHI Conference on Human Factors in Computing Systems, 1290–1294.
  • The ancestor: Anscombe, F. J. (1973). Graphs in statistical analysis. The American Statistician, 27(1), 17–21. And Alberto Cairo’s original Datasaurus.
  • Data: datasets::anscombe, shipped with R, for the quartet. datasaurus_dozen from the datasauRus package (MIT licence) for the thirteen, vendored here as data/raw/datasaurus.csv. Autodesk attaches no licence to the data and welcomed the package; MIT is the package’s.
