Why outbreaks spread exponentially

The most-read article in the Washington Post’s history is less a chart than a simulation you watch, and its argument is that you watched it happen rather than being told the result. That is a different kind of evidence, with a different set of obligations.

THE ORIGINAL

“Why outbreaks like coronavirus spread exponentially, and how to ‘flatten the curve’” by Harry Stevens, The Washington Post, 14 March 2020. Copyright The Washington Post. A single frame of an animated work, reproduced for criticism and review under the Dutch citation right (Auteurswet art. 15a). Not a free licence: it cannot be reused from here. The Post published it free to read.

Harry Stevens, 14 March 2020. Dots bounce around a box; when an infected dot touches a healthy one, it infects it. Four scenarios run in sequence (free-for-all, an attempted quarantine, moderate distancing, extensive distancing), each with its curve building underneath.

How to read it

Each dot is a person moving in a box. Pale blue-grey is healthy.

Orange-brown is currently sick. Contact between a sick dot and a healthy one makes the healthy one sick.

Pink is recovered, and cannot be infected again. The running counts sit beside the box.

The chart underneath fills in as it runs: a stacked area of healthy, sick and recovered, built in real time rather than shown finished. The empty grey stretch on its right is time that has not happened yet.

Each scenario changes one thing: how many dots are allowed to move. Nothing else differs between the runs.

THE CRITIQUE

01 · Describe

An animated box of moving points above a stacked area chart that accumulates as the animation plays. Both are small. The sequence repeats four times with a different movement rule each time, and the reader can restart it.

02 · Analyse

The dots are not data but a model, generated in the reader’s browser. The chart underneath is real data about that model. So the piece is doing two things at once: demonstrating a mechanism, and plotting the output of the demonstration. The join between them is what makes it persuasive, because you see the curve being caused.

03 · Interpret

The claim is mechanistic, not empirical: given that transmission works by contact, reducing contact flattens the curve. The piece is careful to claim nothing about how COVID-19 actually behaved.

04 · Judge

It holds, and it carries a risk the form cannot remove. A simulation is enormously convincing (you watched it), and how convincing it is has nothing to do with whether its assumptions match the world. Stevens’s dots recover with permanent immunity, mix at random, and never travel. None of that is true. The piece works because the claim it makes is narrow enough to survive the simplification. Most simulations shown to the public are not.

THE RECREATION

Every other exhibit in this gallery plots data that already existed. Here the data does not exist until the code runs, which is what this case is about.

Show the R code 
set.seed(42)

simulate <- function(n = 250, moving = 1, steps = 420, box = 100,
                     radius = 2.2, recover = 90, v = 1.1) {
  # state: 0 healthy, 1 infected, 2 recovered
  state <- c(1L, rep(0L, n - 1))
  sick_since <- rep(NA_integer_, n)
  sick_since[1] <- 0L

  x <- runif(n, 0, box); y <- runif(n, 0, box)
  mobile <- rep(FALSE, n); mobile[sample(n, round(n * moving))] <- TRUE
  ang <- runif(n, 0, 2 * pi)
  dx <- ifelse(mobile, cos(ang) * v, 0); dy <- ifelse(mobile, sin(ang) * v, 0)

  out <- vector("list", steps)
  for (s in seq_len(steps)) {
    x <- x + dx; y <- y + dy
    # bounce off the walls
    dx[x < 0 | x > box] <- -dx[x < 0 | x > box]
    dy[y < 0 | y > box] <- -dy[y < 0 | y > box]
    x <- pmin(pmax(x, 0), box); y <- pmin(pmax(y, 0), box)

    inf <- which(state == 1L)
    sus <- which(state == 0L)
    if (length(inf) && length(sus)) {
      d <- as.matrix(dist(cbind(x, y)))[sus, inf, drop = FALSE]
      hit <- sus[rowSums(d < radius) > 0]
      state[hit] <- 1L; sick_since[hit] <- s
    }
    done <- which(state == 1L & (s - sick_since) > recover)
    state[done] <- 2L

    out[[s]] <- tibble(step = s,
                       healthy   = sum(state == 0L),
                       infected  = sum(state == 1L),
                       recovered = sum(state == 2L))
  }
  bind_rows(out)
}

scenarios <- tibble(
  moving = c(1, .75, .35, .12),
  label  = c("Everybody moves", "Three in four move",
             "One in three moves", "One in eight moves")
) |> mutate(label = fct_inorder(label))

runs <- scenarios |>
  mutate(sim = map(moving, \(m) simulate(moving = m))) |>
  unnest(sim) |>
  pivot_longer(c(healthy, infected, recovered),
               names_to = "status", values_to = "n") |>
  mutate(status = factor(status, c("recovered", "infected", "healthy"),
                         c("Recovered", "Infected", "Healthy")))

ggplot(runs, aes(step, n, fill = status)) +
  geom_area() +
  facet_wrap(~label, nrow = 1) +
  scale_fill_manual(values = c(Healthy = "#c2cdc7", Infected = "#8C1C13",
                               Recovered = "#1e7c50"), name = NULL) +
  scale_y_continuous(expand = c(0, 0)) +
  scale_x_continuous(expand = c(0, 0)) +
  labs(title = "Same model, same population, one parameter changed",
       subtitle = "250 people in a box. The only difference is how many of them move",
       x = "Time step", y = "People",
       caption = "Simulated data, 250 agents × 420 steps × 4 scenarios, seed 42") +
  theme(legend.position = "bottom")

The peak falls and widens as fewer people move. That is what “flatten the curve” means, and why the phrase is about the shape rather than the total.

WHAT THE ANIMATION ADDED

set.seed(7)
snap <- local({
  n <- 250; box <- 100; radius <- 2.2; recover <- 90; v <- 1.1
  state <- c(1L, rep(0L, n - 1)); sick_since <- rep(NA_integer_, n); sick_since[1] <- 0L
  x <- runif(n, 0, box); y <- runif(n, 0, box)
  ang <- runif(n, 0, 2 * pi); dx <- cos(ang) * v; dy <- sin(ang) * v
  want <- c(1, 40, 80, 140, 220, 380); keep <- list()
  for (s in seq_len(max(want))) {
    x <- x + dx; y <- y + dy
    dx[x < 0 | x > box] <- -dx[x < 0 | x > box]; dy[y < 0 | y > box] <- -dy[y < 0 | y > box]
    x <- pmin(pmax(x, 0), box); y <- pmin(pmax(y, 0), box)
    inf <- which(state == 1L); sus <- which(state == 0L)
    if (length(inf) && length(sus)) {
      d <- as.matrix(dist(cbind(x, y)))[sus, inf, drop = FALSE]
      hit <- sus[rowSums(d < radius) > 0]; state[hit] <- 1L; sick_since[hit] <- s
    }
    done <- which(state == 1L & (s - sick_since) > recover); state[done] <- 2L
    if (s %in% want) keep[[length(keep) + 1]] <-
      tibble(step = s, x = x, y = y,
             status = factor(state, 0:2, c("Healthy", "Infected", "Recovered")))
  }
  bind_rows(keep)
})

Six frames are not the animation, and the gap between them is what made the original work. Watching a single red dot become a wall of red is an experience; reading six panels is an inspection. Both carry the same information. Only one of them was shared by tens of millions of people, and being honest about that is not the same as recommending it.

WHAT THE SIMULATION ASSUMES

A MODEL IS PERSUASIVE WHETHER OR NOT IT IS RIGHT

Read the code above and notice what it takes for granted. Everyone is identical. Contact is a fixed radius. Recovery happens on a fixed schedule and confers permanent immunity. Nobody dies, nobody travels, and the population is closed. Change any one of those and the curves change shape. None of that weakens the narrow claim, that the peak falls when contact is reduced, which is the only claim Stevens made. It would demolish any attempt to read a number off these curves, and a reader who has just watched a simulation is in the worst possible frame of mind to remember that.
