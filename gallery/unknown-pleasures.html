Unknown Pleasures

A figure from a radio astronomy thesis, lifted onto an album cover, and now probably the most reproduced statistical graphic in existence. It is also a working demonstration of when letting your data overlap is the right call.

THE ORIGINAL

Unknown Pleasures sleeve, Joy Division, Factory Records, 1979. Design by Peter Saville, after Harold D. Craft Jr’s 1970 Cornell PhD thesis. Copyright Factory Records / Peter Saville. Low-resolution copy via Wikipedia, shown at 316 px for criticism and review under the Dutch citation right (Auteurswet art. 15a). Not a free licence: it cannot be reused from here.

Harold Craft plotted 80 successive radio pulses from CP 1919, the first pulsar ever detected, in his 1970 Cornell PhD thesis. The plot was reprinted in the Cambridge Encyclopaedia of Astronomy (1977), where Peter Saville found it and used it, uncredited and inverted to white-on-black, for Joy Division’s Unknown Pleasures in 1979.

How to read it

Each line is one rotation of a neutron star: one pulse, about 1.3 seconds of radio signal. There are 80, stacked from the bottom up.

Left to right is time within a single pulse. All 80 are aligned to the same window, so the peaks line up in the middle.

Height is signal strength. A tall spike is a strong pulse; the wobble either side of it is noise.

Each line is drawn opaque and hides the ones behind it. That occlusion is deliberate, and it is what gives the plot its depth.

Nothing is labelled, at least on the album cover: no axes, no units, no scale. Craft’s thesis version has them.

The underlying plot: Craft, H. D. (1970). Radio observations of the pulse profiles and dispersion measures of twelve pulsars. PhD thesis, Cornell University. Craft’s thesis plate carries axes and units; the sleeve strips them, which is the difference the critique below turns on.

THE CRITIQUE

01 · Describe

Eighty line traces stacked vertically at even intervals, each one filled opaquely so it masks whatever falls behind it. The traces are noisy at the edges and spike near the middle, and the spikes vary in height and position from line to line. No axis, tick or legend.

02 · Analyse

This is a ridgeline plot, and it uses vertical position for two things at once: the baseline of each line encodes which pulse, and displacement from that baseline encodes intensity. That double duty is why the values are unreadable and why the shape is so legible. The occlusion turns a flat grid into an apparent surface.

03 · Interpret

The claim is that the pulses are regular but not identical: they arrive on schedule and vary in strength and shape from one rotation to the next. For an astronomer in 1970 that variation was the finding. You can see it without reading a single number.

04 · Judge

Defensible, for this claim. Eighty overlaid series on one axis would be an unreadable tangle; eighty separate panels would lose the comparison entirely. The ridgeline is the form that keeps both. It is a bad choice the moment anyone needs a value off it, which is why Craft’s thesis, unlike the album, carries axes.

THE RECREATION

Show the R code 
# ggplot draws one layer at a time. One geom_ribbon() for all 80 pulses and
# then one geom_line() would put every line on top of every fill, and nothing
# would be hidden. So each pulse gets its own pair of layers, its ribbon and
# then its line, and the pairs are added from the back row (the top) to the
# front row (the bottom). Each pair paints over everything already behind it.
one_pulse <- function(i) {
  d <- filter(pulsar, pulse == i)
  list(
    # Filled with the ground colour: this is what hides the rows behind.
    # Leave it out and the plot becomes a flat tangle (see below).
    geom_ribbon(data = d, aes(ymin = pulse, ymax = pulse + intensity / 9),
                fill = "black", colour = NA),
    geom_line(data = d, colour = "white", linewidth = .32)
  )
}

# y is the row (which pulse) plus the signal: one position, two jobs
ggplot(pulsar, aes(x = sample, y = pulse + intensity / 9, group = pulse)) +
  map(max(pulsar$pulse):1, one_pulse) +     # back to front
  coord_cartesian(expand = FALSE) +
  theme_void() +                            # no axes, as on the sleeve
  theme(plot.background = element_rect(fill = "black", colour = NA),
        plot.margin = margin(70, 80, 70, 80))   # the sleeve's wide border

80 pulses from CP 1919, 300 samples each, white on black as on the sleeve. Each pulse is drawn over the ones behind it, from the top row down. Data traced from the sleeve by Michael Zöllner, as numbers by Borgar Þorsteinsson, CC BY-NC-SA 4.0, so this chart is CC BY-NC-SA 4.0 too.

WHAT THE OCCLUSION IS WORTH

The only difference between these two is whether each ribbon is filled. Both draw the peaks about twice as tall as the sleeve does, so each one reaches across several rows and the difference has somewhere to show.

Show the R code 
library(patchwork)
ink   <- dsvar_tokens()$ink
paper <- dsvar_tokens()$paper

# The recreation's construction, with two changes: the page's ink on its
# paper rather than the sleeve's white on black, and peaks about twice as tall
# (intensity / 4), so each one reaches across several rows. `filled` is the
# one switch between the two panels.
ridges <- function(filled, title) {
  layers <- map(max(pulsar$pulse):1, function(i) {
    d <- filter(pulsar, pulse == i)
    list(
      if (filled) geom_ribbon(data = d, aes(ymin = pulse, ymax = pulse + intensity / 4),
                              fill = paper, colour = NA),
      geom_line(data = d, colour = ink, linewidth = .3)
    )
  })
  ggplot(pulsar, aes(x = sample, y = pulse + intensity / 4, group = pulse)) +
    layers +
    coord_cartesian(expand = FALSE) +
    labs(title = title) +
    theme_void() +
    theme(plot.background = element_rect(fill = paper, colour = NA),
          plot.title = element_text(colour = ink, face = "bold", size = 12,
                                    family = dsvar_font(), margin = margin(b = 10)),
          plot.margin = margin(14, 18, 14, 18))
}

ridges(FALSE, "Unfilled: a tangle") + ridges(TRUE, "Filled: a surface") +
  plot_annotation(
    caption = "Identical data, identical lines, identical drawing order. The right-hand panel fills each ribbon with the ground colour.",
    theme = theme(plot.background = element_rect(fill = paper, colour = NA),
                  plot.caption = element_text(colour = dsvar_tokens()$ink_3, hjust = 0,
                                              size = 9, family = dsvar_font())))

Occlusion is normally a fault, the thing we spend week 4 fixing with transparency and jitter. Here it is the encoding: hiding the far lines behind the near ones turns a stack of traces into a receding surface, and the surface makes the pattern visible. The rule is not “never overlap”: overlapping must be a decision, and you should be able to say what it buys.

THE SAME PULSES, MADE READABLE

Show the R code 
hm <- ggplot(pulsar, aes(sample, pulse, fill = intensity)) +
  geom_raster() +
  scale_fill_gradientn(colours = dsvar_ramp_light, name = "Intensity") +
  coord_cartesian(expand = FALSE) +
  labs(x = "Time within pulse", y = "Pulse number",
       title = "Intensity on colour",
       subtitle = "Every value readable, the depth gone") +
  theme(legend.position = "none")

prof <- pulsar |>
  summarise(m = mean(intensity),
            lo = quantile(intensity, .1), hi = quantile(intensity, .9),
            .by = sample)

pp <- ggplot(prof, aes(sample, m)) +
  geom_ribbon(aes(ymin = lo, ymax = hi), fill = dsvar_accent(), alpha = .2) +
  geom_line(colour = dsvar_accent(), linewidth = .7) +
  labs(x = "Time within pulse", y = "Intensity",
       title = "The average pulse, with its spread",
       subtitle = "The 10th to 90th percentile across all 80 pulses")

# patchwork's guide collection is broken against ggplot2 4.x, so these are
# placed with plain addition and themed individually. See the README.
hm + pp

Left: nothing is hidden, and the plot has become a grid you read rather than a shape you see. Right: the summary Craft would have published if he only wanted the average, which deletes the pulse-to-pulse variation that made the original interesting.
