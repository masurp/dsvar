# Data Science: Visualisation and Analytics in R

The public website of the MA course *Data Science: Visualisation and Analytics
in R* (DSVAR) at the Vrije Universiteit Amsterdam.

**Read it here: <https://masurp.github.io/dsvar/>**

The course is about the choices that decide which argument a chart makes, and
the rules that guide those choices. Every chart is built in R with ggplot2.
The site holds the weekly pages, lecture slides, work group materials, a
gallery of famous charts rebuilt and critiqued, and the datasets used along
the way.

## What is in this repository

This repository holds only the built site, which GitHub Pages serves as it is.
It is generated from a separate source repository and updated week by week as
the course runs, so a week's materials appear here when that week opens.
Please do not open pull requests against the HTML: changes would be overwritten
by the next release.

Spotted a mistake? Students in the course can raise it on Canvas; anyone else
can open an issue here.
