Data Science: Visualisation and Analytics in R

Welcome to “Data Science: Visualisation and Analytics in R”! The key idea behind this course is that any visualization tries to make an argument, but most datasets can support more than one. The eight-week course is about the choices that decide which argument a chart makes, and the rules that guide those choices. The course is built around the R programming language, and the ggplot2 package in particular, but it is not about programming: it is about using programming to make better charts.

BUILDING A FIGURE: THE SAME SEQUENCE, EVERY WEEK

01QuestionWhat are you asking of the data
02ClaimThe sentence the chart has to earn
03EvidenceWhat the data can actually support
04EncodingThe choice that does the arguing
05AnnotationWhere the honesty lives

One chart in five states, with the same data throughout. The only thing that changes is what its author has decided to show. Step five adds an annotation or highlight, the step that most often gets skipped: a chart without annotation has drawn its data but has not made its claim. Every week we go through the same steps and ask the same questions; what changes is the data and the claim the chart is asked to support.
